# Oathfront

**Forge alliances. Break strongholds.**

A fantasy army strategy playtest for Windows: build your dwarf forces, research new abilities, summon heroes and fight over the central hill. Play solo or online with 3–5 teams and up to two players per team.

## Download and play

[Download the Oathfront Launcher](https://github.com/Zerrrex/Oathfront-Playtest/releases/latest/download/Oathfront-Launcher.zip)

1. Extract the launcher ZIP and run **OathfrontLauncher.exe**.
2. Choose **Install & Play**. On future visits, use **Update & Play** when a new build is available.
3. In the game, select **Play online → Host game** to create a room, or **Find games → Refresh → Join** to join a friend. Room codes remain optional.
4. Choose your seats, mark everyone ready, and let the host start the match. The host must keep the game open.

Every player needs the same game build. Windows 10/11 with .NET Framework 4.8 is supported; friends do not need Unity, a GitHub account or administrator access. The launcher is currently unsigned by Microsoft Authenticode, so Windows may show a publisher/reputation warning on first run. Use the launcher from this repository's Releases page.

The launcher verifies signed update information and archive checksums before installing. Cancelled or failed downloads preserve the installed game. Game files are stored in `%LOCALAPPDATA%\Oathfront`; **Repair install** downloads a fresh copy. Game updates use full archives in this first playtest.

## About this repository

This repository hosts playable releases and their update feed. It does not contain the Unity source project or release signing key. This is an early playtest: balance, art and interface will continue to evolve.
